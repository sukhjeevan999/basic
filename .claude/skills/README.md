# Superpowers Skills

Skills copied from [obra/superpowers](https://github.com/obra/superpowers) v6.3.0
(MIT License, see `LICENSE`) by Jesse Vincent — a general-purpose skill library
for Claude Code covering TDD, systematic debugging, brainstorming, plan writing,
code review, and related collaboration workflows.

These are unrelated to this repository's WordPress themes (`taper-theme/`,
`vin-decoder-theme/`); they were added as project-scoped skills per request,
not authored as part of this project.

Only the `skills/` contents were brought over — the upstream repo's hooks
(e.g. its `SessionStart` hook) and plugin/marketplace registration were not
installed, since those require separate `settings.json` configuration.
